# 오레마스 포켓몬 생성기 (웹 버전)

오레마스(포켓몬식 배틀 팬게임)의 오리지널 포켓몬 생성기입니다.

- **생성기**: 역할·열쇠말·계제 포인트(강약) 기준으로 포켓몬을 만들고, 게임 「붙여넣기」 줄로 내보냅니다.
  - 계제 문장 = 게임 구문 DB 조각을 이어 붙인 것 중 배틀 엔진이 읽는다고 확인된 틀 (G8, 2026-10-20)
  - 속별 = 구글 시트 「오레마스 프로젝트_데이터」 「속별 포텐셜 예시」 탭에서 고르기 / 구문 DB 조합으로 새로 만들기. 페이지를 열 때 시트에서 다시 받음 ([↻ 시트에서 다시 받기])
  - 역할·부수 = 같은 시트 「테이블(싱글)」 「00. 역할」「13. 부수」 (열 때 다시 받음) · 메인 기믹(상태·소지품·구문 DB 타이밍)을 고르면 계제에 그 기믹 줄이 2줄 이상
  - 종족치 = 프라이드 계단(C · C+ · B · B+ · A · A+)을 먼저 고르고 그 안에 분배 — 계산 종족치(원래 합 + 하한·내구·HP·화력·스피드 할증 − 쌍두 할인)가 계단 상한 안. 표는 같은 시트 「프라이드 규칙」 탭 (게임 · 휴대폰 편집과 같은 표, G9, 2026-10-28)
- **입력 · 수집**: 게임과 같은 붙여넣기 줄을 읽어 모읍니다.
- **채점 · 서술형 논평**: 점수와 논평을 남기면 다음 생성부터 반영됩니다.

저장소는 구글 시트(Apps Script 웹 앱)입니다. `apps-script-Code.gs` 가 그 코드입니다.

## 모바일 편집 (`mobile/`)

생성기와 따로 된 페이지입니다. 휴대폰에서 포켓몬·트레이너를 고치고 게임 「붙여넣기」 줄로 복사합니다 (기술·특성·소지품·구문 DB 내장, 자료를 모으지 않음).

- 주소: https://engell00-cmd.github.io/oremas-maker/mobile/
- 소스·다시 만드는 도구: 게임 폴더 `tools/mobile_edit/`
