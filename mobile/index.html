포켓몬 만들기

여기서 포켓몬을 만들고, 마지막에 나오는 한 줄을 게임에 붙여넣으면 끝이에요.

  1. 이름 · 타입을 정해요
  2. 특성 · 기술은 [찾기], 포텐셜은 칸마다 [고르기]
  3. 아래 [줄 복사] → 게임 포켓몬 편집의 [붙여넣기]
구글 시트 동조
페이지를 열 때마다 알아서 받아요. 페이지를 켜 둔 채 시트를 고쳤으면 눌러 주세요.

줄 읽어 오기

게임·시트·생성기의 붙여넣기 한 줄
칸을 길게 눌러 붙여넣은 뒤 [읽기]. 지금 고치던 내용은 읽은 줄로 바뀌어요.

포텐셜
[고르기] = 4.xlsx 「테이블(싱글)」 목록 (+ 게임 목록에만 있는 것) · [짜기] = 문장 직접 짜기. 『속별』·『종족』 목록은 예시예요 — 넣은 뒤 고쳐 쓰세요.

전용 포텐셜
[고르기] = 4.xlsx 「테이블(싱글)」 전용 27개 + 『마검』 (밸런스 제한 없이 다 보여요 · 「○」 자리는 고쳐 쓰기)
줄에는 첫 번째 전용만 들어가요. 2·3번째 전용은 게임이 원래 것을 그대로 둬요.

기술

폼체인지 · 메가진화
폼은 아래 「만든 줄」에 안 들어가요. 폼마다 [폼 줄 복사] → 게임 포켓몬 편집 맨 아래 「폼체인지」 칸 [붙여넣기로 폼 추가]에 붙이고 「종류」를 골라요. 나이트/거다이 기술 · 폼 그림은 게임에서 넣어요.

만든 줄

게임 포켓몬 박스 → 붙여넣기로 추가
줄에 안 들어가는 것: 성별(게임 붙여넣기 창에서 고름) · 그림 · 2·3번째 전용 · 폼 · 기능확장 · 발동 문구 · 개체값 · 소지품. 같은 포켓몬을 덮어쓰면 게임이 이것들을 그대로 둬요.
